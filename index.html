    Choose the Right ESP32 Board or Display for Your Project

    This free ESP32 board and display selector helps you find compatible development boards, ESP32 display modules and touchscreen boards based on the hardware specifications that matter in real-world projects.

    Filter ESP32 hardware by ESP32 family, display technology, screen size, resolution, display interface, touchscreen type, touch interface, PSRAM, GPIO availability, LVGL support, USB and battery support. Compare hardware for an ESP32 touchscreen, an ESP32-S3 display, an ESP32 display for LVGL, an AMOLED touchscreen, an 800×480 display or a board for a larger graphical interface.

    The selector separates mandatory requirements from preferences, making it easier to identify which ESP32 boards and display modules meet your project constraints instead of choosing hardware based only on screen size or headline specifications.

    ESP32 Display and Touchscreen Compatibility

    Choosing an ESP32 display is about more than screen size. Resolution, display interface, touch controller, touch interface, PSRAM, available GPIO and memory requirements can all affect whether a board is suitable for a particular project. A small SPI TFT display can have very different requirements from a large RGB display, while an ESP32-S3 board running a demanding LVGL interface may require substantially more PSRAM and GPIO resources.

    The selector can help you compare hardware for ESP32 touchscreen displays, ESP32-S3 displays, LVGL projects, AMOLED and TFT displays, 800×480 graphical displays, SPI, RGB, 8080 and QSPI displays, capacitive and resistive touchscreens, battery-powered ESP32 projects and HMI or graphical user interfaces.

    For more detailed information about choosing an ESP32 touchscreen, display interfaces, touch technologies, ESP32-S3 hardware, PSRAM and LVGL, see the ESP32 Touchscreen Displays Guide. When you find a suitable board, verify the manufacturer's exact display controller, touch controller, pinout, operating voltage, available memory, GPIO allocation and software-driver support before purchasing.

    Recommended ESP32 Touchscreen Displays

    Use project selection to rank boards for common ESP32 touchscreen projects, then refine the list with technical requirements. The selector does not treat newer or more powerful hardware as automatically better.

    ESP32-S3 vs ESP32-P4

    Choose ESP32-S3 for many conventional touchscreen projects where simplicity, broad board availability and proven graphics support matter. Choose ESP32-P4 when your project genuinely benefits from advanced graphics, MIPI-DSI, camera/MIPI-CSI, larger HMI displays or multimedia-oriented hardware.

    The catalog is deliberately conservative: unknown specifications remain unknown rather than being guessed. Verify exact controller, pinout, voltage, memory and driver support before purchase.
